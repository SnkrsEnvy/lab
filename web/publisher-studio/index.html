Designing the unified publishing surface

Authority before conversion.

Publisher Studio keeps Word-like semantic structure and Acrobat-like page truth powerful precisely because it refuses to pretend they are the same thing.

A professional publishing system should let writers think in paragraphs, headings, fields and sections while letting production teams think in exact pages, crops, links, annotations, redactions and export proof. The difficult part is not placing both toolsets in one window. It is preserving which representation has authority.

In Page Mode, a PDF remains page truth. Edits are bounded deltas over the frozen source. In Flow Mode, semantic blocks remain semantic state. DOCX import keeps the original bytes frozen while Publisher Studio works against a normalized authoring model.

The result is a document workspace where revisions stay reversible, provenance remains inspectable and export never silently promotes a derived representation into source truth.

Core doctrine

FROZEN SOURCE + AUTHORIZED DELTAS

Every consequential change is explicit. UNKNOWN remains visible. A successful command is not automatically successful work.
